# CarePurse logo

Mama's clasp purse with a bolt: her money, and the power it keeps on (light, airtime, data). Black on white.

| File | Use |
|---|---|
| `carepurse-logo.svg` / `.png` | Mark and name, for the deck, README and socials |
| `carepurse-mark.svg` / `carepurse-mark-512.png` | The mark alone, on light backgrounds |
| `carepurse-mark-white.svg` | The mark alone, on black |
| `carepurse-app-icon.svg` / `-512.png` | White mark on a black tile: favicon, app and profile pictures |

In the web app: `apps/web/src/components/LogoMark.tsx`, `src/app/icon.svg` and `apple-icon.png`.
